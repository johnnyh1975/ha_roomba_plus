# Roomba+ 4.3.0b7

**A beta.** Everything in [4.3.0b6](v4.3.0b6.md), plus the fixes from
the stable release [4.2.19](v4.2.19.md).

Needs *Show beta versions* in HACS. Built on **roombapy-prime 0.5.0b2**,
as b6 was.

---

## From 4.2.19: naming rooms shows the map

Configure → *Rooms & zones* asked for names by number, and nothing in
Home Assistant said which room a number was (@liblit). It also opened
with `[formatjs Error: MISSING_VALUE]`.
- **The map is in the form.** Each unnamed room or area is drawn with
  its number, and the empty field with the same number names it.
- **With your iRobot account, only rooms on the map that have no name
  anywhere are asked about.** The account's names count, as everywhere
  else in Roomba+.
- **Without the account, or without a map to show, the step says what
  is missing** instead of asking.
- **900-series robots** see the *Cleaning path* map, with every unnamed
  area numbered.

Details: [4.2.19](v4.2.19.md).

## From 4.2.19: clean zones on Classic robots

`roomba_plus.clean_zone` and the *Clean zone (Smart Map)* button now
work on Classic robots: zone names resolve as the zone select shows
them, and a zone goes out to the robot as a zone (@Hardy-196).

## From 4.2.19: renamed rooms and obstacle pins

- **A room renamed under Configure → *Zone management* can be cleaned
  by its new name.** `clean_room` answered "Unknown room(s)" for it,
  while the card offered exactly that name. The original name keeps
  working.
- **`format=hazards` uses one coordinate frame.** Obstacles and keep-out
  zones from the map were in the map's units, next to stuck pins in
  millimetres from the dock. They are now converted once the map is
  aligned, and each pin says which frame it is in (`space`).

## From 4.2.19: event entities

`event.{name}_mission_completed`, `event.{name}_room_completed` and, on
Classic, `event.{name}_stuck` mirror the bus events as entity states.
Non-admin users get the mission-end signal through them. Prime's
mission-completed event now carries the Classic payload.

## From 4.2.19: guide links and the API version

- **Part sensors carry a `guide_url`** to iRobot's own replacement guide,
  where its parts catalogue has one.
- **The REST API reports version 2.** The `format=hazards` change counts
  as breaking under the rule now written down in API.md.

## From 4.2.19: the coverage map's frame

`image.{name}_coverage_map` publishes `render_extent_mm`: the
millimetres its square image covers.

## From 4.2.19: Prime

- **The REST API exists for Prime-only households.** It was registered
  only when a Classic robot set up. Prime missions now also list their
  rooms by name, and the household summary reports Prime maintenance as
  due when a part is used up.
- ***Rooms overdue* and *Room cleaning history* now exist on Prime
  robots**, as announced in 4.0.0.
