# Roomba+ 4.6.6

**The Vac and Combo Essential are set up on the local connection, and a
Prime room clean started in the iRobot app has a plan.**

Needs **roombapy-prime 0.9.3**; Home Assistant installs it with the
update. An Essential set up from the account needs one step:
[upgrade notes](../docs/UPGRADING.md#v466--from-v465).

---

## The Vac and Combo Essential are Classic robots (@gloopy-purple-liquid, #265)

Three Combo Essentials (SKU `y014020`), moved from Home Assistant's
built-in integration, were set up through the iRobot account as Prime
robots, cloud only. iRobot's cloud refused every status subscription for
them: commands reached the robots, but after the first reading their
state never changed. A start that ran was reported as not delivered.

SKUs starting `Q0` (Vac Essential) and `Y0` (Combo Essential) were listed
as Prime in roombapy-prime, from app code nobody had checked on a robot.
The Prime app's own model list has neither, and they had been running
on the built-in integration's local connection. roombapy-prime 0.9.3
lists them as Classic, and the account flow sets them up on the local
connection like the rest of that generation.

**Already set up?** *Reconfigure* the entry with the robot's IP address
and leave the password empty, or delete it and add the robot again. The
Essential keeps no map of rooms, so there is no room cleaning; start,
stop, dock, battery, bin, errors and the mission history work.

## Prime: a room clean started in the app has a plan (@woopstar, #259)

A room clean started from the iRobot app had no plan in Home Assistant:
only a start from Home Assistant wrote one. @woopstar's three rooms from
the app showed no next room and no remaining time, and the current room
was the number of a room from an earlier mission, for hours.

- **The plan comes from the command that started the mission,** as on
  Classic, when that command is a start sent within ten minutes of the
  mission's start. A run without rooms in its command has no plan; the
  rooms the timeline reports become the list as the robot enters them.
- **A new mission replaces the last one's plan.** It reset the room
  count but kept the planned rooms, which is where the earlier room came
  from.
- **Plans hold room names.** A plan Home Assistant wrote held region
  numbers, while the timeline's room reports are matched by name: such a
  plan showed numbers and did not move on with the robot. A region the
  cloud has no name for keeps its number.

A mission running during the update keeps the plan it had.

Still open in #259: one room listed as a zone in the room select, which
needs a diagnostics download to explain.
