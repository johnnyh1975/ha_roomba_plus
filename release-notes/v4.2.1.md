# Roomba+ 4.2.1

Two things that read wrongly on some robots, some logging hygiene, and
the Platinum quality tier.

## Mission progress stuck at 0%

Elapsed time was added up from the gaps between messages the robot
sends, and any gap longer than two minutes was discarded — a rule meant
for recharges and restarts.

It cannot tell those apart from a robot that simply has nothing new to
say, and during steady cleaning there often is nothing new. Real time
went in the bin and the total lagged badly. One tester's i7+ read 0%
for an entire mission.

**Two changes.** Progress now measures from the mission start time the
robot itself reports — no adding up, nothing to discard. And where time
still is accumulated, a quiet stretch counts as cleaning when the robot
was running on both sides of it, rather than being thrown away for
being long.

## The room display could lag by minutes

The same stopped clock delayed room changes. On top of that, a check in
front of the room advance asked "has this room had roughly enough
time" — a fair question when a charging pause is the only clue, and the
wrong one when the robot has just said it was driving and then stopped.

One tester watched his robot move from the kitchen to the bathroom and
the display follow **nine minutes later**. It now advances on the drive
ending, with only a short floor to keep repositioning inside one room
from counting.

## Also

- **Navigation telemetry is no longer labelled "live" when it is not.**
  The robot writes it up after a run finishes, so mid-mission it
  usually describes the previous one
- **Diagnostics now show the position chain** — points collected,
  alignment state, room polygons, door markers. Each link fails
  silently and nothing said which one

## Platinum

The integration now declares Home Assistant's **Platinum** quality tier,
its highest. All 41 rules are met — strict typing, an async dependency
and an injected web session are what separate it from Gold, and the
async rewrite in 4.2.0 was the last of those.

A build check now verifies the claim against the rule file rather than
trusting the word in the manifest.
