# Roomba+ 4.2.0b5

Everything in b1 through b4 still applies — see those notes for the
async rewrite. This adds the three fixes also released as 4.1.6.

## Cleaning a zone started a mission that ended immediately

The robot's map data lists every region, zones included, and marks each
one as a room or a zone. Roomba+ ignored that marking and offered every
region as a room, so a zone's id went out as a *room* id. No room has
that number, so the robot found nothing to clean and reported success
about a minute later (@theChef163).

Zones are recognised as zones now.

## Gentle mode was missing on S9-series robots

The switch appeared only when the robot reported the setting as
`gentle`; S9+ robots call the same feature `gentleMode`
(@ScenicSystemsLLC). Both names are accepted.

## An empty navigation record counted as a measurement

Two of three robots on one firmware report mission navigation statistics
with every counter at zero, during a mission and after it (@veronoicc).
Those records were feeding a per-robot measure of localisation quality
built from numbers the robot never took. Empty records are ignored now;
a genuine zero still counts.

## Still what this beta is for

The async rewrite has met little hardware. **The failure to watch for is
a command that silently does nothing** — the robot does not move,
nothing appears in the log.
